The Tavern Sit-Stand table

Two sizes, one finish, height-adjustable from 29" to 44.5" — a different build from the Pangea, but it shares the same magnetic rail, so the rail accessory line fits both (the Player Desk is Pangea-only).

The Tavern is our height-adjustable line. It raises and lowers so the same table works seated, standing, or somewhere in between — useful for long sessions, for mixed-height groups, and for spaces that need one table to do several jobs.

It is not a Pangea variant. Different construction, build, and finish. But it shares the same magnetic rail as the Pangea, so the rail accessory line fits both — the Player Desk is the one Pangea-only exception. If you're choosing between them, the construction difference matters more than the size does.

Two 44×30s can be combined into a full 44×60 layout. No brackets or hardware are involved — you position the two tables together and they line up. That also means you can separate them again for a different room layout without undoing anything.

Crank or electric

The 44×30 uses a manual hand crank; the 44×60 has an electric lift as standard.

That's worth thinking about beyond convenience. A crank has no motor, no control board, and no duty cycle — there's less to go wrong and nothing to plug in. An electric lift is faster and easier mid-session, particularly if you're changing height often or the table is in a venue where staff adjust it repeatedly.

How it differs from a Pangea

  • Construction. The Tavern is a commercial-grade powder-coated steel frame with high-density engineered wood panels in a waterproof performance laminate. A Pangea is steel framed too, but with solid Malaysian oak rails and toppers and base panels in premium MDF with an oak veneer. See What Zola tables are made of.
  • The recessed vault. A Pangea has a 2.5″-deep recessed vault; the Tavern is a flat playing surface with a low 1.25″ rail. Both carry the same magnetic rail, so rail accessories fit either.
  • Accessories carry across. Both tables use the same magnetic rail, so the Flex and rail accessory line fits either — the oak line and the Utility Series both attach to it, and you choose between them by durability and look, not by table. The one exception is the Player Desk, which fits the Pangea only. See Which accessories fit my table?.
  • Finish. Tavern comes in Smoked Walnut only. Pangea comes in Dark Walnut and Cerused Oak.

Using one commercially

The Tavern is built for high-traffic spaces and it's the table we'd point a café or venue at. If that's your setting, get in touch through our contact page before ordering — commercial installs get scoped directly rather than sold on consumer terms, and warranty coverage for commercial use is handled separately.
