The Table Topper Set

The Table Topper Set is precision-fit, magnet-held panels that drop over the recessed vault for a flat surface; the padded Storage Cube is where they live when the vault is open.

The Table Topper Set is a set of precision-fit, magnet-held panels that drop over the recessed play vault to give you a flat, level surface — a gaming table on game night, a dining or work table the rest of the week, without moving anything into a closet.

How it works

The panels are held in place by magnets — set them in and they seat flush. Removing them takes seconds, and the game underneath is still exactly where you left it, which is the quiet advantage of a recessed vault: a campaign in progress can stay set up under a dinner.

Sizing and finish

Topper Sets are sold per table size and in Dark Walnut or Cerused Oak to match your table. A topper for one size will not fit another — see Which accessories fit my table?.

Where the panels go when they're off the table

They're solid, veneered, and finished on the visible face — leaning them against a wall works for an evening, but it's not where you want them living.

The Table Topper Storage Cube ($129.99) is the purpose-built answer: a padded oak cube sized to hold the panels upright, protected, and out of the way rather than stacked on a floor. The Storage Cube XL ($199.99) does the same job with more room, and also takes table leaves and dividers as well as toppers — the one to get if you run a configuration with extension leaves or use dividers regularly.

If you're not buying a cube yet, some things are worth doing regardless:

  • Store panels upright, not stacked flat — weight on a stack presses grit into the faces
  • Keep something soft between panels — a blanket or felt; face-to-face contact with nothing between them is how the finish gets marked
  • Avoid damp or hot storage — a garage that swings between humid and freezing is unkind to a veneered panel; the panels are veneered specifically for dimensional stability, and extreme storage undoes that
  • Keep them out of direct sun — fading is excluded from warranty coverage, and a panel that's faded unevenly against the rest of the set is very visible once it goes back in

The need for topper storage isn't obvious from the product page, and people often discover it after the table arrives. If you know you'll switch between game and dining use regularly, it's worth adding the cube to the same order as your table — accessories ship parcel, so consolidating avoids a second delivery.
