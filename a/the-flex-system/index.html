The Flex system

A tray that clips to the rail, with interchangeable inserts dropped into it — one rail position does several jobs depending on the game.

Flex is a two-part idea: a tray that clips to the Omnitrack rail, and inserts that drop into it. Change the insert and the same rail position does a different job.

It exists because what a player needs at the table changes by game. A deckbuilder wants card holders; a wargame wants bins for tokens; a co-op wants somewhere to stand up reference cards. Rather than buying a different accessory for each, you buy trays once and swap what sits in them.

The tray

Flex Tray (2 pack) — $59.99. This is the base. The standard tray is solid oak; the Flex Tray Utility Series (2 pack) — $36.99 is the hard-wearing version for cafés and high-traffic use.

How people actually use it

The common pattern is one tray per player position, then a small set of inserts shared across the group and swapped by game. You don't need an insert per player per type.

If you're starting out, trays plus one insert type covering your most-played game is a better first purchase than a full set. Add from there once you know what you reach for.

Storage

Inserts are small and easy to lose. The Storage Bin (2 pack) — $49.99 and the organizers are worth pairing with a Flex set if you're accumulating inserts.

Which tables it fits

Flex clips to the magnetic rail, and both the Pangea and the Tavern use the same magnetic rail — so Flex trays and inserts fit either table. See Which accessories fit my table?, and send us a photo through our contact page if you have any questions about your setup.
