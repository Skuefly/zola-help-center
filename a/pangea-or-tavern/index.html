Pangea or Tavern — which one?

Pangea is the recessed-vault gaming table for a home; Tavern is the height-adjustable one built for cafés and flexible spaces.

They're not two sizes of the same idea. They're built differently, for different rooms.

The short version

Pangea if you want a dedicated gaming table with a recessed vault, in a home, at a fixed height.

Tavern if you want height adjustment — a table that works seated and standing, in a space that changes use through the day.

What actually decides it

The vault. A Pangea's 2.5″ recess is the whole point — the game sits down in it, pieces don't get knocked off the edge, and the topper set closes it into a flat dining surface. The Tavern doesn't have that; it's a flat playing surface with a low rail.

If the recessed vault is what you want, size is your only real question and the Tavern isn't in the running.

Height adjustment. The Tavern raises and lowers. For a café where staff reconfigure, or a room that's a games table some evenings and a standing work surface others, that flexibility is worth more than the vault.

Weight and permanence. A Pangea is heavy and stays where it's built. A Tavern is a third to half the weight and easier to move and reconfigure.

Accessories carry across

Good to know if you own both, or plan to: the rail accessory line carries across — both tables use the same magnetic rail, so cup holders, Flex trays, Flex inserts, and armrests fit either. The one exception is the Player Desk, which fits the Pangea only. Size-specific items — Table Topper Sets, Table Panels, and play mats — are still made per Pangea size and don't interchange between sizes. See Which accessories fit my table?.

If it's for a venue

The Tavern is what we'd point a café, bar, or game store at — it's specified for that traffic, and it pairs with the Utility Series.
