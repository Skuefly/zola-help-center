Changing your order

Address, size, finish, and added items can usually change before the order ships — the cutoff is when freight is booked, not when you placed it.

Most changes are possible while the order hasn't shipped. The real cutoff is when the freight shipment gets booked, not when you placed the order — so on a pre-order there's often a lot of room.

Message us through our contact page with your order number and what you'd like changed. The sooner the better.

Shipping address

Changeable before freight is booked. Once a carrier has the shipment and an address, redirecting it is a carrier reroute rather than an edit — sometimes possible, sometimes not, and it can add cost and delay.

If you've moved or mistyped an address, tell us immediately rather than waiting to see whether it matters.

Size or finish

Usually possible before shipping. Two things to know:

  • It may change the date. If you're switching to something on a different pre-order timeline, you inherit that timeline. We'll tell you what the new date is before making the change.
  • It's an edit, not a return. Much simpler than receiving one table and sending it back — see Returning a table for what that involves if the table has already arrived.

Adding items

Often yes, especially if the original hasn't shipped. Adding accessories to an existing table order also saves a second delivery.

If it can't be added — usually because the order is already being processed — a separate order is the fallback, and we'll say so rather than leaving it ambiguous.

Splitting a mixed order

By default, an order containing a table and accessories ships together. If you'd rather have the accessories now and the table when it's ready, ask and we can usually split it.

Worth doing if the table is on a longer pre-order date and you want the accessories in the meantime.

Holding an order

If you're moving house, travelling, or otherwise not ready to receive a 242 lb freight delivery, we can hold the order until a date you give us. Tell us the date and we'll sit on it — much better than a delivery arriving at an empty house.

Cancelling

Also possible before shipment. Payment is taken at order, so a cancellation is a refund rather than a voided charge — see How refunds work.
