The Utility Series and the standard line

Two parallel accessory lines — the standard line is solid oak, the Utility Series is the hard-wearing version built for cafés and high-traffic use.

We make some accessories twice. The standard line and the Utility Series cover the same jobs — trays, cup holders — in different materials, for different rooms.

Nothing was replaced. They run in parallel, and which one is right depends less on budget than on how hard the accessory is going to be used.

The difference in one line

The standard line is solid oak. The Utility Series isn't.

That includes the Flex Tray: the standard Flex Tray is solid oak; the Utility Series version is the hard-wearing equivalent. Same function, different material.

Which to choose

Standard line — solid oak. The right choice for a home table. It's the warmer piece, it matches the oak rails, and in a household it will outlast the games you're playing on it.

Utility Series. Built for cafés, game stores, libraries, and anywhere accessories get handled by strangers dozens of times a day, cleaned aggressively, and occasionally dropped. It's specified for that duty rather than for looks.

If you're outfitting a venue, the Utility Series is what we'd point you at — not because the oak wouldn't survive, but because replacing a Utility piece is cheap and replacing an oak one isn't.

Flex inserts

The Flex system is a base tray that other inserts drop into — card holders, chit holders, and bins — so one rail position does several jobs depending on what's seated in it. Inserts come in a range of colours.

Material, not table

Utility versus oak is a material choice, not a table choice. Both attach to the same magnetic rail, and the Pangea and the Tavern share that rail — so either line works on either table. Pick by how hard the piece will be used: oak for a home table, the Utility Series for a café or high-traffic venue.
